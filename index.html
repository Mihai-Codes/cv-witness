The Industry Shift

Why Hyper-Tailored Resumes Get Flagged

Recruiters and modern hiring platforms like Greenhouse and Ashby are actively detecting AI-generated resumes that mirror job postings line-by-line. Mirroring burns trust: verified truth wins interviews.

The Naive AI Failure Mode

What typical tools do

  • Job description mirroring: Rewrites bullets to match JD phrasing verbatim, triggering automated similarity flags.
  • Metric fabrication: Invents percentages, headcounts, or tool mastery to fill gaps, collapsing in interview rounds.
  • Parsing-breaking typography: Inserts em dashes, smart quotes, or icon images that break legacy ATS text extractors.
  • Unchecked multi-page overflow: Spills two trailing lines onto a second page with unbalanced margins.
The cv-witness Gate

What cv-witness guarantees

  • Candidate human voice: Describes your real work in your voice: the JD informs emphasis only, never wording.
  • The [FILL: ...] gate: Gaps in proven evidence become visible markers rather than made-up metrics.
  • Strict ASCII punctuation: Only plain hyphens in date ranges and real text throughout, avoiding parser crashes.
  • Mechanical verification: pdftotext extraction and single-page geometric bounds checks run on every build.
Core Architecture

The Four Hard Gates

cv-witness is intentionally narrow. It is not an auto-apply bot. It is the CV engine whose output cannot lie, backed by structural gates that an agent cannot talk past.

1. Anti-Mirroring Lint

Runs scripts/jd_overlap.py to mechanically flag shared 4+ word runs between your resume and the posting before any PDF renders.

2. Merged-State Proof

Any open-source PR cited on the CV is verified via the GitHub API first. Closed or unmerged work is never presented as merged.

3. Provenance Isolation

Your master resume (foundation.md) and verification log (provenance.md) remain local, gitignored, and never published.

4. Mechanical PDF Gate

Every build is validated with pdftotext text extraction, exact page count measurement, and zero-placeholder scans.

How It Runs

The cv-witness Loop

A single command coordinates the end-to-end flow while keeping you in full control of the truth.

STEP 01

Target & Map

The agent ingests the target job posting and cross-references requirements against your master resume and provenance files. Gaps stay marked.

STEP 02

Human Voice Synthesis

Drafts bullets following the write-like-human rules: active verbs, real metrics, zero AI fluff, and zero borrowed job description phrasing.

STEP 03

Mechanical Verification

The headless engine renders an A4 single-page PDF, checks for glyph leaks, measures vertical symmetry, and validates overlap lints.
